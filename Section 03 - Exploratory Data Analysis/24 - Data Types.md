# Data Types - MLE Exam Essentials

- **Numerical data**: measurable quantities  
  - *Discrete*: integer counts, no fractions (e.g. # of purchases)  
  - *Continuous*: any value incl decimals (e.g. height, time, rain amount)  

- **Categorical data**: categories w no inherent numeric meaning  
  - e.g. gender, state, product category  
  - numbers assigned are arbitrary; no order/size comparison  

- **Ordinal data**: categories with a meaningful order  
  - e.g. star ratings (1-5 stars: 5 > 1)  
  - mix of categorical + numeric  
  - can often treat as discrete numerical data  

*Why care?*  
Different ML algorithms / techniques handle these data types differently  
so identifying type matters for model building/feature encoding.

# AWS Glue DataBrew - Must Know for AWS MLE Specialty

---

### What is Glue DataBrew?  
- No-code visual data preparation and cleaning service  
- Use interactive UI to clean and normalize data without coding  
- Speeds up data prep for ML and analytics by up to 80%  

---

### Data Sources Supported  
- Amazon S3  
- Redshift  
- Aurora  
- Glue Data Catalog tables  

---

### Features  
- 250+ pre-built transformations (e.g., filtering anomalies, data conversion, fixing invalid values)  
- Helps automate common data cleaning tasks easily
